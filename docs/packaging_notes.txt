Packaging
=========

https://packaging.python.org/tutorials/packaging-projects/

Requires: hatch  (pip install hatch)

1. Install/update hatch:
    pip install --upgrade hatch

2. Build distribution archives:
    hatch build

3. Check the distribution archives:
    pip install twine && twine check dist/*

4. Upload to PyPI:
    hatch publish

5. Run tests across all Python versions:
    hatch test --all
    # or target a specific version:
    hatch test --python 3.12

6. Create release at https://github.com/ikvk/imap_tools

7. Mirror:
    cd to repo
    Cleaning old references to remote branches:
        git fetch --prune
    Push:
        git push --prune git@gitflic.ru:ikvk/imap-tools.git +refs/remotes/origin/*:refs/heads/* +refs/tags/*:refs/tags/*

    https://dev.to/sourcelevel/how-to-properly-mirror-a-git-repository-19d9
